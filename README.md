# Book Reading List

A small browser app to add books, mark them as read/unread, search the list, and remove entries. The list is saved in your browser using localStorage.

## Run locally
Open `index.html` in a browser. No installation is needed.

## Deployment
Deploy this folder as a static site using GitHub Pages or Vercel. After deploying, test the live site and add the real URL to this README and your portfolio.
